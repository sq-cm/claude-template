# This folder — persistent memory

Authoritative detail: [Memory Protocol SOP](../../Resources/SOPs/Memory%20Protocol%20SOP.md).

- `MEMORY.md` is maintainer-only — never write local facts there.
- Local facts: session note in `Sessions/`, then `/memory-reconcile` folds it into `context.md`.
- Per-project local facts fold into that project's own files under `Projects/<name>/` instead — decision trail into `HISTORY.md`, current truths (live state, operative gotchas) into `CONTEXT.md` — distinct reconcile-written surfaces, still never `MEMORY.md`.
- This file is Orchestrator-only, like the root CLAUDE.md.
