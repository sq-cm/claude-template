# Vault Templates

Obsidian note templates. Used by the Obsidian Templater plugin (or manually) to pre-populate new notes.

---

## Files

| Template | Purpose |
|---|---|
| `Daily Note.md` | Daily journaling / task capture scaffold |
| `Weekly Note.md` | Weekly review and planning scaffold |

---

## Usage

In Obsidian: set this folder as your Templates folder in Templater or core Templates plugin settings. Templates are invoked via `Templater: Open Insert Template Modal` or the command palette.

These are starting points — edit to match your workflow.
