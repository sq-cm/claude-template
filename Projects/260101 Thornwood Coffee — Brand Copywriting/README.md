# Thornwood Coffee — Brand Copywriting

## What this is
A brand copywriting project with an intentional Odin checkpoint built in. You cannot declare this done without running Checkpoint A (before drafting) and Checkpoint B (before finalising). That's the point.

## Learning objectives
- How Remi (brand strategy) and Finn (copywriting) hand off to each other
- **How to invoke Odin for Checkpoint A and Checkpoint B** — the core quality gate
- How checkpoint log entries are written
- How repo consultation works (Resources/Git/INDEX.md)

## What's already done
- Client brief (Briefs/)
- Remi's brand positioning: tone defined, audience section missing
- Finn's copy doc: 3 of 6 hero headlines written; Checkpoint B instruction embedded
- Checkpoint log: one example Checkpoint A entry (from Remi's handoff) to show the format

## What you need to complete

### Step 1 — Remi's section
1. Open `Working/remi-brand-positioning.md`
2. Complete the **Target Audience** section (marked TODO)

### Step 2 — Checkpoint A (before Finn drafts)
3. Open `Working/checkpoint-log.md` — read the example entry
4. Invoke Odin for Checkpoint A on Finn's remaining headlines (see log for invocation format)
5. Log Odin's response in the checkpoint log

### Step 3 — Finn's copy
6. Open `Working/finn-copy-doc.md`
7. Complete headlines 4–6 using Remi's positioning + Odin's Checkpoint A advice

### Step 4 — Checkpoint B (before declaring done)
8. Invoke Odin for Checkpoint B review of the completed copy doc
9. Log the response
10. Apply any changes Odin recommends

### Step 5 — Deliver
11. Move completed copy to `Deliverables/Brand Copy — Thornwood Coffee.md`
