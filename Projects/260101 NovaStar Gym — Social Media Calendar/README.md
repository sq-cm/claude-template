# NovaStar Gym — Social Media Calendar

## What this is
A 4-week social media calendar for a gym client. Week 1 is fully planned. Weeks 2–4 are skeleton frames you need to fill.

## Learning objectives
- How Sam routes to Sage (content strategy) then Juno (social) then Cleo (visual AI prompts)
- How Cleo's image prompt format works — embedded alongside post copy
- How a structured calendar deliverable is assembled from multiple contributors
- Marlowe's role in tracking a multi-week deliverable

## What's already done
- Client brief (Briefs/)
- Sage's content strategy notes (pillars, tone, posting rhythm)
- Week 1: 5 posts fully written with copy + Cleo's image prompts

## What you need to complete
1. Open `Working/social-calendar.md`
2. Complete Weeks 2, 3, and 4 (dates + platforms filled; copy and image prompts empty)
3. Follow Week 1 as your format template
4. Move the completed calendar to `Deliverables/Social Media Calendar — NovaStar Gym.md`

## How to start
Tell Sam: *"Continue the NovaStar Gym social calendar — I need Weeks 2 through 4."*

Sam will route to Juno (copy) and Cleo (visual prompts) in sequence.

## Note on Cleo's prompts
Each post needs an image prompt in Cleo's format:
```
**Visual prompt (Cleo):** [Subject]. [Style/mood]. [Colour palette]. [Composition note]. Aspect ratio: [1:1 or 9:16].
```
See Week 1 for examples.
