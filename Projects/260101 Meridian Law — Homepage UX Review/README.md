# Meridian Law — Homepage UX Review

## What this is
A partially complete UX audit for a law firm homepage. Cross-functional: the UX/UI Designer, the Copywriter, and the QA Compliance Reviewer (accessibility compliance).

## Learning objectives
- How the Orchestrator routes to the UX/UI Designer for UX work
- How the Copywriter's copywriting review layers onto UX findings
- How the QA Compliance Reviewer's WCAG compliance checklist works as a standalone deliverable
- Compiling outputs from multiple team members into one final report

## What's already done
- Client brief (Briefs/)
- The UX/UI Designer's audit: Navigation, Hero, and CTA sections complete (3 of 7)
- The QA Compliance Reviewer's WCAG checklist: all items listed, none evaluated

## What you need to complete
1. Open `Working/ux-audit-draft.md`
2. Complete sections 4–7: **Trust Signals**, **Mobile Experience**, **Page Speed Perception**, **Conversion Flow**
3. Open `Working/quinn-wcag-checklist.md` — evaluate each item (Pass / Fail / N/A + notes)
4. Compile both documents into a single final report: `Deliverables/UX Review Report — Meridian Law.md`

## How to start
Tell the Orchestrator: *"I want to continue the Meridian Law UX review."*

The Orchestrator will route to the UX/UI Designer, who will pick up from section 4.
