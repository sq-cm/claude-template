# Daily Notes

One note per day. Created automatically by Obsidian's Daily Notes plugin or Templater.

## Naming convention

```
YYYY-MM-DD.md
```

Example: `2026-04-17.md`

## Template

`Vault/Templates/Daily Note.md` — configure this path in Obsidian's Daily Notes or Templater settings.

## Structure

Files sit flat in this folder — no subfolders. Chronological order by filename.

## Notes

- Configure Obsidian Daily Notes plugin to point to this folder as the output path
- Do not rename files after creation — date-based naming is relied on by calendar and dataview plugins
