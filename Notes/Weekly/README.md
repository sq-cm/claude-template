# Weekly Notes

One note per week for reviews and planning.

## Naming convention

```
YYYY-Www.md
```

Example: `2026-W19.md`

## Template

`Vault/Templates/Weekly Note.md` — apply via Templater or copy manually when creating a new weekly note.

## Structure

Files sit flat in this folder — no subfolders. Chronological order by filename.

## Notes

- Week numbers follow ISO 8601 (Monday start, zero-padded: W01–W53)
- Create manually at the start of each week or automate via Templater periodic notes
