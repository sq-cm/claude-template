# Clippings

Saved web pages, articles, and reference material. Capture first, curate later.

## How content gets here

- **Obsidian Web Clipper** (recommended) — configure output path to this folder in Web Clipper settings
- **Manual** — paste or drag content into a new `.md` file

## Naming convention

No strict convention — Web Clipper uses page title by default. Acceptable.

## Structure

Files sit flat in this folder. No required subfolders — add date-prefix or topic subfolders if volume warrants it.

## Notes

- No curation required at capture time — just get it in
- Clippings are reference material, not working notes — don't edit source content, annotate separately
