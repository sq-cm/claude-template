# Canvas

Visual thinking files — Obsidian Canvas (`.canvas`) and Excalidraw (`.excalidraw.md`).

## File types

| Extension | Tool |
|---|---|
| `.canvas` | Obsidian Canvas — native infinite whiteboard |
| `.excalidraw.md` | Excalidraw plugin — hand-drawn style diagrams |

## Naming convention

Descriptive name preferred over date-based:
```
[Topic or Purpose].canvas
[Topic or Purpose].excalidraw.md
```

## Structure

Flat folder. No subfolders required unless volume warrants grouping by project.

## Notes

- Requires Obsidian Canvas (built-in) or Excalidraw plugin for `.excalidraw.md` files
- Canvas files are not plain markdown — do not edit raw JSON manually
