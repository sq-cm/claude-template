AI Team — Onboarding Guide

Everything you need to start working with your AI team — or to set up a new vault for a client.

Last synced:  ·  Source of truth: CLAUDE.md

What is this?

You have access to a team of 23 AI specialists — a copywriter, SEO strategist, UX designer, brand strategist, and more. A coordinator called Sam (the Orchestrator) receives everything you send and routes it to the right person. You don't manage the routing — you just describe what you need.

Using Claude Code: Claude Code is a chat interface that runs in your terminal or IDE. Type your message and press Enter — that's it. Everything in this guide assumes you have Claude Code open with this workspace as your working directory.

How a request flows

Here's what happens when you send a real request — from your message to a finished deliverable.

You
"I need blog content for a new coffee brand targeting specialty coffee enthusiasts in Australia."
Sam — routing
Content strategy first, then copy. Handing this to Sage (Content Strategist) to build the content framework, then Finn (Copywriter) will write from it. Tate (Project Manager), you're on delivery tracking.
Sage — Content Strategist
Before drafting, checking the repo library for content strategy frameworks. Running Checkpoint A with Odin (Senior Adviser) before committing to a structure…

Here's the content architecture: three pillar topics — Origin Stories, Brewing Methods, and Ethical Sourcing. Supporting cluster topics mapped to search intent. Brief prepared for Finn.
Finn — Copywriter
Working from Sage's brief. Running Checkpoint B before delivery…

First article drafted: "Why Single-Origin Coffee Tastes Different (And Why It Matters)." 800 words, conversational but informed. Ready for Quinn's pass.
Quinn — QA Reviewer
Result: Pass. Article aligns with brief. No unverified claims. Tone consistent. One suggestion: add a source citation on the altitude flavour profile claim. Returning to Sam.
Sam — handoff complete
Article delivered to Projects/[Client]/Deliverables/. Quinn flagged one citation — Finn will add it. Let me know when you're ready for article two.

How to talk to the team

Three ways to address the team. Pick the one that matches how much you already know.

Open request

"I need a first draft of a client welcome email for a new skincare brand."

No @ needed. Sam reads your request and routes it to the best-fit specialist.

Direct address

"@{Copywriter} write a 200-word homepage intro for Meridian Law. Tone: authoritative but approachable."

Use @{RoleToken} when you know who you need. Bypasses Sam's routing step.

Both @{Copywriter} and @Finn work — use whichever feels natural.

Multi-step request

"I need a full social calendar for NovaStar Gym — strategy, post copy, and visual direction for Instagram."

Sam will loop in Sage, Juno, and Cleo in sequence. You'll see the handoffs happen.

Setup Steps

Run /onboard in Claude Code to automate most of this. Manual steps below for reference.
  1. 1

    Create the client folder

    Duplicate the Claude - TEMPLATE folder. Rename it Claude - [ClientName]. This folder is the entire workspace — it must be opened as the working directory in Claude Code.

  2. 2

    Remove the template comment

    Open CLAUDE.md and delete line 1 if it reads:

    <!-- TEMPLATE: Rename this folder to "Claude - [YourCompany]" before first use. -->
  3. 3

    Set up secrets

    Copy .env.example to .env. Fill in your Anthropic API key. Confirm .env is in .gitignore — never commit it. Check Vault/Memory/MEMORY.md contains no secrets before any git push.

  4. 4

    Verify SOP paths

    Confirm Resources/SOPs/Advisor Checkpoints SOP.md exists. This path must resolve for Odin checkpoint invocations to work. If missing, copy from the template.

  5. 5

    Install Caveman mode

    Reduces Claude's output tokens ~65% by stripping filler. Recommended default: lite.

    Windows:

    irm https://raw.githubusercontent.com/JuliusBrussee/caveman/main/hooks/install.ps1 | iex

    macOS / Linux:

    bash <(curl -s https://raw.githubusercontent.com/JuliusBrussee/caveman/main/hooks/install.sh)

    Then activate: /caveman lite

  6. 6

    Install recommended plugins

    Run each pair of commands in Claude Code. These add context-window management, skill authoring, and UI generation capabilities.

    /plugin marketplace add mksglu/context-mode
/plugin install context-mode

/plugin marketplace add obra/superpowers
/plugin install superpowers

/plugin marketplace add anthropics/claude-plugins-official/plugins/skill-creator
/plugin install skill-creator

/plugin marketplace add anthropics/claude-plugins-official/plugins/frontend-design
/plugin install frontend-design

    Restart Claude Code after all four installs to activate.

  7. 7

    Open in Claude Code and verify

    Open the folder as your working directory. Use the prompt below to confirm routing works correctly.

    Verification prompt — copy and send this:

    "Who's on the team and what does each person do?"

    Expected: Sam responds with a roster summary, listing each specialist's name and role. If you get an error or no routing, confirm CLAUDE.md is in the root of your working directory and try again.

  8. 8
