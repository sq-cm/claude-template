AI Team — Onboarding Guide

Everything you need to start working with your AI team — or to set up a new vault for a client.

Last synced:  ·  Source of truth: CLAUDE.md

What is this?

You have access to a team of 20 AI specialists — a copywriter, SEO strategist, UX designer, brand strategist, and more. You talk to them through Claude Code. A coordinator called the Orchestrator receives everything you send and routes it to the right person. You don't manage the routing — you just describe what you need.

How to talk to the team

There are three ways to address the team. Pick the one that matches how much you already know.

Open request

"I need a first draft of a client welcome email for a new skincare brand."

No @Name needed. The Orchestrator reads your request and routes it to the best-fit specialist.

Direct address

"@{Copywriter} write a 200-word homepage intro for Meridian Law. Tone: authoritative but approachable."

Use @{RoleToken} when you already know who you need. Bypasses the Orchestrator's routing step.

Multi-step request

"I need a full social calendar for NovaStar Gym — strategy, post copy, and visual direction for Instagram."

The Orchestrator will loop in the Content Strategist, Social Media Manager, and Visual AI Producer in sequence. You'll see the handoffs happen.

Setup Steps

Run /onboard in Claude Code to automate most of this. Manual steps below for reference.
  1. 1

    Create the client folder

    Duplicate the Claude - TEMPLATE folder. Rename it Claude - [ClientName]. This folder is the entire workspace — it must be opened as the working directory in Claude Code.

  2. 2

    Remove the template comment

    Open CLAUDE.md and delete line 1 if it reads:

    <!-- TEMPLATE: Rename this folder to "Claude - [YourCompany]" before first use. -->
  3. 3

    Set up secrets

    Copy .env.example to .env. Fill in your Anthropic API key. Confirm .env is in .gitignore — never commit it. Check Vault/Memory/MEMORY.md contains no secrets before any git push.

  4. 4

    Verify SOP paths

    Confirm Resources/SOPs/Advisor Checkpoints SOP.md exists. This path must resolve for @{SeniorAdviser} checkpoint invocations to work. If missing, copy from the template.

  5. 5

    Install Caveman mode

    Reduces Claude's output tokens ~65% by stripping filler. Recommended default: lite.

    Windows:

    irm https://raw.githubusercontent.com/JuliusBrussee/caveman/main/hooks/install.ps1 | iex

    macOS / Linux:

    bash <(curl -s https://raw.githubusercontent.com/JuliusBrussee/caveman/main/hooks/install.sh)

    Then activate: /caveman lite

  6. 6

    Open in Claude Code and verify

    Open the folder as your working directory. Send a test message — Sam should respond and route correctly. Try @{HRLead}, @{SeniorResearcher}, and @{SEOSpecialist} to confirm they're reachable.

  7. 7

    Apply a theme (optional)

    Rename the team with characters from a theme — Vikings, Greek myths, Studio Ghibli, etc. This can be done now or any time later.

    "Set theme to Vikings"

    The Orchestrator researches character names, matches them to roles, shows a preview, and asks for confirmation before changing anything.

  8. 8

    Import reference repos

    Drop GitHub repo URLs into Resources/Git/IMPORT.md and run /import-repos. The team consults these repos for best-practice guidance on relevant tasks.

Vault Structure

The root is reserved for named top-level folders only. New persistent storage goes under Vault/ — never at root level.

Claude - [YourCompany]/
├── .claude/
│ └── commands/
│ ├── onboard.md ← /onboard command (run first)
│ └── import-repos.md ← /import-repos command
├── Inbox/ ← staging area for unrouted material
├── Notes/ ← daily notes, canvas files, clippings
├── Projects/
│ └── [ProjectName]/
