# Thornwood Coffee — Brand Copywriting

## What this is
A brand copywriting project with an intentional @{SeniorAdviser} checkpoint built in. You cannot declare this done without running Checkpoint A (before drafting) and Checkpoint B (before finalising). That's the point.

## Learning objectives
- How the Brand Strategist and the Copywriter hand off to each other
- **How to invoke the Senior Adviser for Checkpoint A and Checkpoint B** — the core quality gate
- How checkpoint log entries are written
- How repo consultation works (Resources/Git/INDEX.md)

## What's already done
- Client brief (01 Briefs/)
- The Brand Strategist's brand positioning: tone defined, audience section missing
- The Copywriter's copy doc: 3 of 6 hero headlines written; Checkpoint B instruction embedded
- Checkpoint log: one example Checkpoint A entry (from Remi's handoff) to show the format

## What you need to complete

### Step 1 — Brand Strategist's section
1. Open `02 Working/remi-brand-positioning.md`
2. Complete the **Target Audience** section (marked TODO)

### Step 2 — Checkpoint A (before the Copywriter drafts)
3. Open `02 Working/checkpoint-log.md` — read the example entry
4. Invoke the Senior Adviser for Checkpoint A on the Copywriter's remaining headlines (see log for invocation format)
5. Log @{SeniorAdviser}'s response in the checkpoint log

### Step 3 — Copywriter's copy
6. Open `02 Working/finn-copy-doc.md`
7. Complete headlines 4–6 using the Brand Strategist's positioning + the Senior Adviser's Checkpoint A advice

### Step 4 — Checkpoint B (before declaring done)
8. Invoke the Senior Adviser for Checkpoint B review of the completed copy doc
9. Log the response
10. Apply any changes @{SeniorAdviser} recommends

### Step 5 — Deliver
11. Move completed copy to `03 Deliverables/Brand Copy — Thornwood Coffee.md`

## How to start
Tell the Orchestrator: *"Continue the Thornwood Coffee brand copy — I need the Brand Strategist to finish the audience section, then the Copywriter to complete the headlines."*

Before Finn drafts, check `Resources/Git/INDEX.md` for any repos tagged `copywriting` or `brand-voice`. Narrate what you found and what (if anything) you applied. Log this in the checkpoint log.
