# NovaStar Gym — Social Media Calendar

## What this is
A 4-week social media calendar for a gym client. Week 1 is fully planned. Weeks 2–4 are skeleton frames you need to fill.

## Learning objectives
- How the Orchestrator routes to the Content Strategist then the Social Media Manager then the Visual AI Producer (visual AI prompts)
- How the Visual AI Producer's image prompt format works — embedded alongside post copy
- How a structured calendar deliverable is assembled from multiple contributors
- The Project Manager's role in tracking a multi-week deliverable

## What's already done
- Client brief (01 Briefs/)
- The Content Strategist's content strategy notes (pillars, tone, posting rhythm)
- Week 1: 5 posts fully written with copy + the Visual AI Producer's image prompts

## What you need to complete
1. Open `02 Working/social-calendar.md`
2. Complete Weeks 2, 3, and 4 (dates + platforms filled; copy and image prompts empty)
3. Follow Week 1 as your format template
4. Move the completed calendar to `03 Deliverables/Social Media Calendar — NovaStar Gym.md`

## How to start
Tell the Orchestrator: *"Continue the NovaStar Gym social calendar — I need Weeks 2 through 4."*

The Orchestrator will route to the Social Media Manager (copy) and the Visual AI Producer (visual prompts) in sequence.

## Note on Cleo's prompts
Each post needs an image prompt in the Visual AI Producer's format:
```
**Visual prompt (Cleo):** [Subject]. [Style/mood]. [Colour palette]. [Composition note]. Aspect ratio: [1:1 or 9:16].
```
See Week 1 for examples.
