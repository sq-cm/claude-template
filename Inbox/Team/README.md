# Team

The shared inbox for notes about the team: roster thinking, working agreements, handoffs, and cross-persona context that isn't tied to a single project.

## What goes here

- Working notes on how the team operates (conventions, decisions, agreements)
- Cross-project context worth keeping in shared view
- Draft thinking before it becomes an SOP, a persona change or a project brief
- Shared material that's been captured but not routed anywhere yet

## Naming convention

No strict convention. Descriptive names work better than dates:
```
[Topic or Purpose].md
```

## Structure

Flat folder. Add topic subfolders only if volume warrants it.

## Notes

- Shared context, not a Deliverable. The Orchestrator doesn't route client work here
- Governance lives elsewhere: durable rules go in `Resources/SOPs/`, persona files in `.claude/agents/`, persistent memory in `Vault/Memory/`
- For private notes use `Inbox/Personal/`
